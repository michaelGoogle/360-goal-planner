# Calculations (archive)

This folder is the **V0-13 and earlier** tree. It is not edited.

The live model, workbook and twins from V0-14 on live in
[`docs/calculations/`](../calculations/README.md). Start there:
[Calculations.md](../calculations/Calculations.md),
[CHANGELOG.md](../calculations/CHANGELOG.md), and
[Calculations V0-25.xlsx](../calculations/Calculations%20V0-25.xlsx).

To clone a new tree, copy `calculations/` to a sibling folder at the same
depth under `docs/` so the build script still finds `src/` and `../HU`.
